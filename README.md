# Subspace

A retro-futuristic starship bridge and space-console theme for the [rpg-engine](https://github.com/stefanocaronia/rpg-engine) dashboard, for any game system: warm amber telemetry and subspace cyan on deep-space console slate by night, crisp data-slate silver-blue by day.

| | Light | Dark |
|---|---|---|
| Page | `#e8ecf5` data-slate silver-blue | `#070a14` deep space |
| Text | `#10192e` command navy | `#edf2ff` starlight |
| Accent | `#9b3e00` burnt amber | `#ff9c42` console amber |
| Strong | `#e69d24` gold | `#66d9ff` subspace cyan |

## Its shapes

Cut-corner console cards with a subtle scanline grid, a delta vector ornament, and a left accent bar; pill buttons and tabs; double-framed rounded portraits; astrometrics starfield grid under the page and a starship vector silhouette at the head of the page. Needs rpg-engine 0.22 or later.

## Install

- In the dashboard: **Packages > Add**, paste `https://github.com/fjordsec/rpg-engine-theme-subspace`.
- Or from a terminal: `rpg package install https://github.com/fjordsec/rpg-engine-theme-subspace`.

Then choose **Subspace** in **Settings > This page > Game style**.
